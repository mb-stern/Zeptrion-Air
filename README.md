# Zeptrion Air

IP-Symcon-Modul für **Feller zeptrionAIR**.

## Entwicklungsstand

Frühe Entwicklungsphase.

Die Integration soll die lokale zeptrionAIR-HTTP-Schnittstelle nutzen und vorhandene zeptrion-Installationen in IP-Symcon integrieren.

Geplante Schwerpunkte:

- lokale Kommunikation mit zeptrionAIR-Geräten
- Licht schalten und Status erfassen
- Dimmer / DALI untersuchen und integrieren
- Storen steuern
- virtuelle Storenposition anhand der Laufzeit berechnen
- Möglichkeiten für ereignisbasierte Statusmeldungen untersuchen
- möglichst geringe Polling-Last

## Branches

- **main** – stabil
- **beta** – Testversion
- **development** – laufende Entwicklung

## Voraussetzungen

- IP-Symcon ab Version 8.2
- Feller zeptrionAIR
